Belum punya Personal Access Token? Klik di sini
  1. Buka github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Pada Repository access, pilih Only select repositories dan pilih repository website ini saja.
  3. Pada Permissions → Repository permissions, set Contents = Read and write.
  4. Klik Generate token, salin tokennya (hanya tampil sekali), lalu tempel di kolom Token di atas.

⚠️ Token disimpan di browser Anda sendiri agar panel ini bisa langsung menyimpan perubahan ke GitHub tanpa server tambahan. Gunakan token fine-grained yang hanya diberi akses ke repository ini, jangan pernah membagikan token Anda, dan gunakan panel ini hanya di perangkat pribadi yang terpercaya.

Tentang Panel Admin ini

Panel ini membaca dan menulis konten langsung ke file data/db.json di repository GitHub Anda melalui GitHub REST API, menggunakan Personal Access Token yang Anda masukkan saat login. Setiap perubahan yang disimpan akan otomatis membuat commit baru, dan GitHub Pages akan membangun ulang situs dalam waktu singkat (biasanya 30–60 detik).

Periksa status koneksi ke GitHub API, hak akses repository, dan sisa kuota API (rate limit).
